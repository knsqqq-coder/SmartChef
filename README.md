# SmartChef

Бұл папкада зертханалық жұмыс №2 үшін дайындалған бастапқы Django жобасы сақталған.

## Құрамы

- `config` — Django project
- `recipes` — Django app
- `.venv` — Python виртуалды ортасы
- `.env` — Gemini API key үшін жергілікті файл үлгісі
- `.gitignore` — құпия және уақытша файлдарды Git-ке қоспау үшін
- `requirements.txt` — орнатылған Python пакеттері

## Іске қосу

```powershell
.venv\Scripts\python.exe manage.py check
.venv\Scripts\python.exe manage.py migrate
.venv\Scripts\python.exe manage.py runserver
```

Сервер ашылғаннан кейін браузерде:

```text
http://127.0.0.1:8000/
```

## Ескерту

`.env` ішіндегі `PASTE_YOUR_KEY_HERE` орнына Google AI Studio-дан алынған жеке API key қойылады. Кілтті скриншотқа, есепке немесе ортақ архивке қоспау керек.

## Lab 6 — дайындау режимі

`recipe_format.py` Gemini жауабын қатаң тексереді. Жаңа құрылымды рецепт `SMARTCHEF_JSON_V1` префиксі мен жаңа жолдан кейін сол `SavedRecipe.recipe` өрісінде сақталады; модель мен SQLite схемасы өзгермейді. Ескі plain-text рецепттер бастапқы мәтін күйінде көрсетіледі, ал дайындау режимі олар үшін HTTP 422 қайтарады.

Демо режимі: процестің ортасына `SMARTCHEF_DEMO=1` қойғанда бекітілген оқу демосы жасалады және Gemini API шақырылмайды. Бұл режим жеке `.env` кілтін қажет етпейді; жобаның `.env` файлы өзгертілген жоқ.

Қабылдау тесттері нақты нәтиже бойынша орындалды. Demo режимі `SMARTCHEF_DEMO=1` тохиргоосунда жергиликтүү фикстураны колдонот жана Gemini API чакырбайт; live режиминде `SMARTCHEF_DEMO=0`, `.env` ичиндеги `GEMINI_API_KEY` жана `GEMINI_MODEL=gemini-3.8-flash` менен Gemini чакырылат (бул текшерүүдө live API суроосу жүргүзүлгөн жок). Катуу JSON текшерүүсүнөн өтпөгөн бош/ката жооп сакталбайт; эски plaintext рецепт өзгөртүлбөйт жана бышыруу үчүн HTTP 422 көрсөтөт.\n\nТексеру командаларының осы орындалуы: `manage.py check` — қатесіз; `manage.py test recipes` — 14 тест өтті; `makemigrations --check --dry-run` — `No changes detected`; `node --check` екі скриптте де қатесіз.

### Жаңа дайындау режимі

`/cook/<recipe-token>/` бір ғана ағымдағы қадамды көрсетеді. Сессиядағы `open_step` пен `completed_steps` бөлек сақталады; растау тек ағымдағы қадам нөмірімен қабылданады. Қайта жүктеу жаңа бастайды. Draft-тан шығу оны сессиядан өшірмейді. Сақтау бұрынғы `get_or_create` жолын қолданады және Gemini шақырмайды.

### Қауіпсіз demo ортасы

Жаңа таза көшірмеде `.env.example` файлын `.env` деп көшірсең, `SMARTCHEF_DEMO=1` Gemini-ді шақырмай жергілікті оқу фикстурасын қолданады. Қолданыстағы `.env` бұл жұмыста өзгертілмейді және Git-ке қосылмайды.

### Lab 7 — ұсынысты салыстыру және undo

SavedRecipe-ге ұсыныс жасау, бастапқы рецептпен салыстыру, қабылдау/бас тарту және соңғы қабылданған өзгерісті бір рет undo жасау бар; каталог, сақтау және cooking mode сақталған. `SMARTCHEF_DEMO=1` жергілікті оқу фикстурасын көрсетіп Gemini шақырмайды, ал `SMARTCHEF_DEMO=0` жарамды `.env` кілтімен live Gemini API-ге сұрау жібереді.
